# 📱 Messenger - Real-Time Chat Application

A modern, feature-rich iOS messaging application built with Swift and Firebase, providing seamless real-time communication with multimedia support.

## ✨ Features

### 💬 **Rich Messaging**
- **Text Messages** - Send and receive instant text messages
- **Photo Sharing** - Share images with automatic compression and optimization
- **Video Messages** - Send and view video content with built-in player
- **Location Sharing** - Share your current location with interactive maps
- **Message Deletion** - Delete sent messages with real-time updates

### 🔐 **Authentication & Security**
- **Email/Password Registration** - Secure user account creation
- **Firebase Authentication** - Industry-standard authentication system
- **Profile Management** - Custom profile pictures and user information

### 👥 **User Discovery**
- **User Search** - Find and connect with other users
- **Real-time User List** - Browse available users in real-time
- **Conversation Management** - Start new conversations and manage existing ones

### 🎨 **User Experience**
- **Modern UI** - Clean, intuitive interface built with MessageKit
- **Real-time Updates** - Instant message delivery and read receipts
- **Offline Support** - Local data persistence with Realm
- **Progress Indicators** - Loading states and progress feedback

## 🛠 Tech Stack

### **Core Technologies**
- **Swift** - Primary programming language
- **UIKit** - iOS user interface framework
- **iOS 9.0+** - Minimum deployment target

### **Backend & Database**
- **Firebase** - Complete backend-as-a-service solution
  - **Firebase Auth** - User authentication and management
  - **Firebase Realtime Database** - Real-time data synchronization
  - **Firebase Storage** - Media file storage and management
  - **Firebase Analytics** - User behavior tracking
  - **Firebase Crashlytics** - Crash reporting and monitoring

### **Key Dependencies**
- **MessageKit** - Modern messaging UI framework
- **InputBarAccessoryView** - Customizable message input interface
- **RealmSwift** - Local database for offline data persistence
- **SDWebImage** - Efficient image loading and caching
- **JGProgressHUD** - Loading indicators and progress feedback

### **Architecture**
- **MVC Pattern** - Model-View-Controller architecture
- **Singleton Pattern** - Shared managers for database and storage
- **Delegate Pattern** - Inter-component communication
- **Real-time Listeners** - Firebase real-time data synchronization

The app includes multiple view controllers for a complete messaging experience:
